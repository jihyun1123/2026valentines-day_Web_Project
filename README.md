# 💌 답정너 발렌타인데이 웹사이트

## 프로젝트 개요
- **주제:** 발렌타인데이 고백 웹사이트  
- **컨셉:** Gmail 링크 클릭 → 답정너 고백 페이지 등장 → YES/NO 선택 구조  
- **페이지:** 총 2페이지  
  1. 메일 📩 이모지 점점 확대  
  2. 발렌타인 편지 + 답정너 버튼
